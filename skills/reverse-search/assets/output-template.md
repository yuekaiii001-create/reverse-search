# 输出结构模板

**不是每次都要走完。** 用户只要一个环节时（比如只问「去哪找」），只给那一环，不要塞满九段。

下面的结构适用于完整咨询。

---

```markdown
## 1. 你要的其实是

[一句话复述真实目标，不是用户说的关键词]

⚠️ 待确认：[需要用户补的信息]

## 2. 直接搜会遇到

[中介 / 广告 / 同质化 / 钓鱼信息 —— 具体说，不要泛泛而谈]
```

## 简版（用户只要一个环节时）

```markdown
[直接给那一环，不加其他段落]

> 提醒：逆向搜索降低寻找成本，提高筛选成本。[一句针对这个场景的具体风险]
```

例：

> **去哪找**：房东急租的入口不在租房平台，在「怎么快速出租房子」这类教程的评论区 —— 那里的留言人是自己走出来的。站内搜 `出租难 求助`、`房子空置 怎么办`。
>
> 提醒：急租背后可能是房屋有硬伤。见面先看漏水、噪音、邻居，别急着交定金。
