# 接触方案

## 姿态：不是救世主，也不是收割者

原版方法论说「以救世主的姿态介入」—— **这个说法是错的，而且会害了你。**

- **救世主姿态**意味着你比对方高。对方会本能抗拒，即使你的提议对他有利。
- **收割者姿态**对方迟早会察觉，然后报复 —— 举报、曝光、差评，代价由你承担。

**正确姿态：真实交换。**

他要解决一个麻烦，你要他手上的东西。双方都是来解决问题的，平等。

你是「能解决这个问题的人」，不是「来拯救你的人」。

这不是道德要求，是效率要求 —— **平等姿态的成交率高于救世主姿态。**

## 三个原则

1. **先给价值，再提需求** —— 第一句话说的是你能解决什么，不是你要什么
2. **透明** —— 你是谁、你要什么、条件是什么，一开始就说清楚
3. **可退出** —— 明确告诉对方「不合适也没关系」。压力越低，回复率越高

## 话术骨架

```
[确认对方的处境] + [说明你的身份和目的] + [给出关键条件] + [低压力的行动建议] + [退出选项]
```

**例 · 租房**

> 看到你在处理这套房子的出租。我这边正在找 XX 区、预算 X 的房子，能长期租、不走中介。
> 如果还空着，方便的话可以私信聊两句；不合适也没关系。

**例 · 清库存**

> 看到你在清这批货。我做 XX，需要的正好是这类。
> 想问一下剩余数量和大概的价格区间，合适的话我可以一次拿走。如果已经处理掉了就不用回。

**例 · 找工作（反向用）**

> 看你在帖子里说团队缺人、项目卡着。我做 XX，做过 XX，能上手。
> 如果还在找，我把简历发你；不匹配也麻烦说一声，我就不打扰了。

## 什么不能做

| 不能做 | 为什么 |
|---|---|
| 假装身份（假买家、假同行、假官方） | 一旦被拆穿，交易和口碑一起毁 |
| 制造虚假稀缺（「我这边也有别人在谈」） | 操控，且容易被验证为假 |
| 用对方的困境压价 | 短期占便宜，长期失掉口碑。发愁的供给方往往还有别的选择 |
| 刷屏、群发、逐个私信 | 骚扰，会被封号，还毁掉整个渠道 |
| 诱导对方泄露隐私（证件、账户、家庭信息） | 越界 |
| 绕过平台规则（导流站外、规避抽成） | 违规，风险由你承担 |

## 什么时候停止接触

- **对方明确拒绝** → 立刻停止。不追问、不换号再来。
- **你开始觉得「这个人很好骗」** → 停下来。这是危险信号，针对的是你自己。
- **对方的困境是「没有别的选择」，而不是「想快点成交」** → 这种情况下你的议价优势来自对方的绝望，不是来自你提供的价值。

  **这不是逆向思维，这是趁火打劫。** 退出。

第三条要特别留意：它和正常情况的表面区别很小。判断方法 —— 问自己一句：**「如果他不答应我，他还有别的出路吗？」** 如果答案是「基本没有」，那你不该动这个交易。
