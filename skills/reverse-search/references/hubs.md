# 信息枢纽

## 判据

一个地方是不是枢纽，只看一条：

> **发愁的人会不会在这里公开说出自己的困境？**

- 广告位、分类信息网站首页 → **不是**枢纽。那里是供给方花钱买的摊位，站着的全是专业卖家。
- 教程视频的评论区 → **是**枢纽。求助的人在那里暴露了身份、地点和具体困难。

## 分类（按优先级）

### 1. 求助现场 —— 优先级最高

发愁的人主动发帖求救的地方。

- 教程 / 经验分享内容的评论区
- 「怎么办」类问答的提问区和回答区
- 本地生活社区的求助板块
- 群里有人直接开口问的场合

**为什么优先级最高**：他们是自己走出来的，不需要你去猜。身份、地点、困难都是现成的。

### 2. 退场现场

供给方正在结束经营或持有、急着变现的地方。

- 清仓、转让、撤店信息栏
- 倒闭 / 结业类话题
- 法院拍卖、资产处置公告
- 闲置平台的「搬家急出」「关店清仓」标签

### 3. 失败者聚集地

亏过、踩过坑的人聚集的地方。情绪浓度最高，也最愿意接受新方案 —— 因为他们已经证明了老办法不管用。

- 行业踩坑 / 复盘话题
- 「创业失败」类社群
- 维权、投诉类板块

### 4. 垂直行业圈

行话密集，外人进不去，但供给质量最高。

- 行业论坛、贴吧、专业社区
- 本地行业群、车友会、业主群、家长群
- 展会、线下活动

### 5. 官方登记渠道

不产生情绪，但**可核验**。用于尽调，不用于发现。

- 抵押 / 拍卖登记、产权 / 资质公示
- 企业注销 / 清算公告
- 行业协会公开名录

## 怎么判断一个枢纽值不值得进

| 信号 | 判断 |
|---|---|
| 有真实的地点、时间、金额细节 | 真 |
| 只有情绪没有信息 | 引流号，跳过 |
| 同一个账号反复发同类内容 | 中介伪装，跳过 |
| 帖子下面有实质回复（问细节、报价格） | 活跃，值得进 |
| 最新帖子在半年以前 | 已死，换地方 |

## 输出时给什么

不要只写「去小红书找」。要给到**可执行的程度**：

- 具体平台 / 板块
- 可用的站内搜索词（配合 [queries.md](queries.md)）
- 判断信息真假的线索
- 这个枢纽的活跃度

## 边界

不要抓取需要登录才能看的数据，不要收集与当前需求无关的个人信息，不要绕过平台访问限制。

**公开可见 + 允许参与**，两条都满足才用。
