# 搜索词构造

## 公式

```
[目标资源] + [供给方身份] + [困境词] + [地域 / 时间]
```

不是每项都要有，但**至少要有困境词** —— 没有它，搜到的就还是红海。

## 困境词库

| 类型 | 词 |
|---|---|
| 急迫 | 急、紧急、撑不住、扛不住、最后一周、月底前 |
| 亏损 | 血亏、亏本、砸手里、套牢、压资金 |
| 退场 | 倒闭、清仓、结业、转让、撤店、注销 |
| 求助 | 怎么办、有没有办法、求助、求建议、怎么解决 |
| 失败 | 失败经验、踩坑、复盘、教训 |

## 四类查询，用途不同

| 类型 | 用途 | 例 |
|---|---|---|
| **求助型** | 找到公开表达困境的人 | `房东 房子租不出去 怎么办` |
| **交易型** | 找到具体供给和条件 | `个人 转租 无中介 押一付一` |
| **内容型** | 找教程 / 经验帖，**重点在评论区** | `如何快速出租房子` |
| **社群型** | 找圈子 | `XX 行业群 交流`、`本地 二手 群` |

**内容型的评论区才是金矿。**

教程视频下面留言「我也遇到这个问题，我的房子在 XX」的人，是主动暴露了身份和地点的真实供给方 —— 他不需要你去猜，是他自己走出来的。

## 按平台调整措辞

| 平台 | 措辞特点 |
|---|---|
| 搜索引擎 | 完整疑问句，长尾词 |
| 短视频（抖音 / 快手） | 口语化、情绪化。搜**话题标签**和**评论区**，不要只搜标题 |
| 小红书 | 生活化。`求助`、`救救`、`有没有姐妹` 这类词有效 |
| 知乎 | 疑问句式。`如何看待`、`为什么`、`怎么办` |
| 论坛 / 贴吧 | 行话、黑话。先潜水摸清词汇再搜 |
| 本地平台 | 加区域限定词：`XX 区`、`XX 附近` |
| 闲置交易平台 | 按标签搜：`搬家急出`、`关店清仓`、`低价转让` |

## 生成之后自检

- [ ] 每条词都带困境词或情绪词吗？
- [ ] 换一个人来搜，会搜到同样的东西吗？会 → 还是红海，重写
- [ ] 能直接复制粘贴到搜索框吗？不能 → 太抽象
- [ ] 出现「中介」「代理」「官方」这类词的，删掉

## 词会失效

同一批词用久了会失效 —— 供给方会被引流号轰炸，然后学会换地方、换说法。

**如果搜出来的结果里广告占比超过一半，说明这批词已经红了。** 回到第三步重新推演，不要加大搜索量。
