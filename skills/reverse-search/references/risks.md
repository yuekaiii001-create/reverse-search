# 筛选与尽调

## 核心风险公式

> **逆向搜索降低了寻找成本，但大幅提高了筛选成本。**

| | 直接搜索 | 逆向搜索 |
|---|---|---|
| 信息量 | 多 | 少 |
| 竞争 | 激烈 | 少 |
| 价格 | 贵 | 便宜 |
| 对方身份 | 专业卖家，信息相对规范 | **因为着急才出现的人** |
| 主要成本 | 比价 | 尽调 |

「急」本身不是问题。**「急」的原因才是问题。**

## 急的背后可能是什么

| 表面 | 可能的真相 |
|---|---|
| 急租 | 房屋有硬伤：漏水、噪音、凶宅、即将拆迁、邻居纠纷 |
| 急售 | 产权不清、抵押未解、共有人不同意、税费异常 |
| 急招 | 岗位是坑：欠薪、强制加班、老板难相处、团队要散 |
| 急转 | 生意本身不成立，接手即亏 |
| 急清仓 | 货有问题：临期、瑕疵、型号过时、售后无保障 |

**也可能是真的急** —— 资金周转、搬家、家庭变故。

两种情况从表面分不出来，只能靠尽调。

## 尽调清单

### 通用

- [ ] 对方的身份，以及他和这个东西的关系 —— 是本人吗？有权处置吗？
- [ ] 为什么急？说得出具体原因吗？前后说法一致吗？
- [ ] 有没有第三方能验证 —— 邻居、同事、工商信息、共同熟人
- [ ] 价格和市场价差多少？**差得离谱 = 有隐情**

### 房产

产权归属、共有人、抵押 / 查封状态、现有租约、物业费欠缴、不同时段实际看房、周边环境与噪音

### 劳动

公司工商信息、社保缴纳记录、薪资发放历史、离职员工评价、合同条款、试用期约定

### 交易 / 货源

货权归属、质量抽检、售后责任、退换条款、交付方式、发票

### 通用红线

- **不预付、不转账给个人账户、不交「诚意金 / 定金」给未经核验的对方**
- 书面协议，写明标的、价格、交付、违约、退出条件
- 保留所有沟通记录
- 分阶段付款，每阶段有可验证的交付物

## 必须输出的话

触发本 skill 时，输出结尾必须包含：

> 逆向搜索降低了寻找成本，但会提高筛选成本。「急」的背后可能是机会，也可能藏着隐性问题。接触时保持清醒的尽调意识，不要因为对方的焦虑而替对方买单。

## 涉及专业领域时

房产、劳动、金融、医疗、法律、高价值交易 —— 提醒用户核验官方信息，必要时咨询专业人士。

## 什么时候完全停止

用户的目标本身违法，或明显会伤害他人：

1. 停止逆向搜索规划
2. 说明不能协助，以及原因
3. 给出合法、安全的替代方案

不要只说「我不能帮你做这个」就结束 —— 用户要的是解决问题，堵住一条路就要给另一条。
